# Задание 4. Проектирование продажи ОСАГО

1. Реализация osago-aggregator
   - Технологии: Kotlin/Spring Boot
   - Основные функции:
     - Прием заявок от core-app
     - Работа с API страховых компаний
     - Отслеживание статусов заявок
     - Возврат результатов в core-app
   
2. Хранилище данных:
 - Требуется своя БД PostgreSQL для:
   - Хранения заявок
   - Статусов обработки
   - История взаимодействий со страховыми

3. API для core-app:
   - Kafka (асинхронное взаимодействие):
     - топик osago.requests – приём новых заявок
     - топик osago.updates – публикация предложений от страховых

4. Интеграция core-app ↔ osago-aggregator через Kafka:
   - Масштабируемость
   - Возможность перезапуска без потери данных
   - Реализация паттерна "отправил-и-забыл"

5. API для веб-приложения в core-app
   - GraphQL API:
     - Создание заявки ОСАГО
     - Получение решений по страховым компаниям

6. Интеграция веб-приложения ↔ core-app через GraphQL API
 - GraphQL Subscriptions — фича GraphQL, которая позволяет публиковать изменения о сущностях в рамках одного GraphQL API.

7. Паттерны отказоустойчивости
   - Для osago-aggregator:
     - Circuit Breaker - при вызовах API страховых
     - Retry - для временных ошибок
     - Timeout - на ожидание ответа
   - Для core-app:
     - Rate Limiting - на GraphQL API
     - Timeout - на вызовы osago-aggregator
