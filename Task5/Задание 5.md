# Задание 5. Проектирование GraphQL API

1. Анализ текущего REST API:

   - 3 основных ресурса:
     - GET /clients/{id} - основная информация о клиенте
     - GET /clients/{id}/documents - документы
     - GET /clients/{id}/relatives - родственники

   - Проблемы текущей реализации:
     - N+1 проблема при запросе связанных данных
     - Фиксированные наборы данных в ответах
     - Необходимость делать несколько запросов для получения полной информации
